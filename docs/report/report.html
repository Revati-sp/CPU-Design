General-purpose registersR0, R1, R2, R3 (8 bits each)

CMP0xA1010 aa bb 00000000Ra, RbRa − Rb, flags onlyZ N

aa / bb = register code (00 = R0, 01 = R1, 10 = R2, 11 = R3)  •  iiiiiiii = immediate  •  dddddddd = RAM address  •  fields shown as 0 must be 0.
