# MiniCPU-8

An 8-bit educational CPU with its own 16-bit ISA, a two-pass assembler, and a
step-by-step simulator that prints the registers, flags, and a RAM block after
**every** instruction.

| Program | Written in | Result (RAM[0xF0]) |
|---------|------------|--------------------|
| A: 8² | MiniCPU-8 assembly | `0x40` = **64** |
| B: 5! | C, manually translated to MiniCPU-8 assembly | `0x78` = **120** |

Report: [`docs/CPU_Design_Report.pdf`](docs/CPU_Design_Report.pdf)

## Quick Start

```bash
git clone https://github.com/Revati-sp/CPU-Design.git
cd CPU-Design
python3 run_demo.py
```

This one command assembles both programs, runs them, prints the full trace,
checks both results, and saves the traces to `output/`. It should end with:

```text
SUMMARY
[PASS] Program A: 8^2 = 64   RAM[0xF0] = 0x40 =  64   5 steps  output/square8_trace.txt
[PASS] Program B: 5! = 120   RAM[0xF0] = 0x78 = 120  36 steps  output/factorial_trace.txt
[PASS] All MiniCPU-8 demonstrations completed successfully.
```

To check everything (tests + demos + report) in one go: `python3 validate.py`
(exit status 0 means everything passed).

## Requirements

- Python 3.9 or newer. Uses the standard library only, so there is nothing to install.
  On Windows, type `python` instead of `python3`.
- Optional: a C compiler (`cc`/`gcc`). The test suite uses it to compile
  `programs/factorial.c` and check that it prints `5! = 120`. Without a
  compiler, that one test is skipped.
- Optional: `reportlab`, needed only to rebuild the PDF (see [Report](#report)).

## Individual Commands

| Command | Purpose |
|---------|---------|
| `python3 run_demo.py` | Both programs, full traces, PASS/FAIL |
| `python3 run_demo.py --quiet` | PASS/FAIL summary only |
| `python3 assembler.py programs/square8.asm` | Print the assembly listing (add `-o image.hex` to save the RAM image) |
| `python3 cpu.py programs/factorial.asm` | Run any program and print its full trace |

| `python3 validate.py` | Tests + demos + report check |

## Testing

```bash
python3 -m unittest discover -s tests -v
```

The tests cover:

- the encoding of every instruction, checked against hand-computed words
- labels, directives, and number formats
- 12 assembler error cases, each reported with its line number
- every ALU operation and the Z/N flags
- LOAD/STORE, jumps, and HALT
- faults: invalid opcode, non-zero reserved bits, and the infinite-loop guard
- decoding all 65,536 possible words and re-assembling them back to the same word
- Program A = 64, and Program B = n! for n = 1…5
- that the saved traces in `output/` match the simulator's current output
- that the table below matches `isa.py`, and that the expected output above is
  the real output

## Instruction Set

Each instruction is one 16-bit word, stored high byte first:
`[15:12] opcode | [11:10] ra | [9:8] rb | [7:0] imm8/addr8`.
Any field an instruction does not use must be `0`, and opcode `0xE` is reserved
(the CPU stops with an invalid-opcode error).

| Mnemonic | Opcode | Operands | Encoding | Operation | Flags |
|----------|--------|----------|----------|-----------|-------|
| `NOP` | 0x0 | — | `0000 00 00 00000000` | no operation | - |
| `LDI` | 0x1 | Ra, imm8 | `0001 aa 00 iiiiiiii` | Ra ← imm8 | - |
| `LOAD` | 0x2 | Ra, [addr] | `0010 aa 00 dddddddd` | Ra ← RAM[addr] | - |
| `STORE` | 0x3 | Ra, [addr] | `0011 aa 00 dddddddd` | RAM[addr] ← Ra | - |
| `MOV` | 0x4 | Ra, Rb | `0100 aa bb 00000000` | Ra ← Rb | - |
| `ADD` | 0x5 | Ra, Rb | `0101 aa bb 00000000` | Ra ← Ra + Rb | Z N |
| `SUB` | 0x6 | Ra, Rb | `0110 aa bb 00000000` | Ra ← Ra − Rb | Z N |
| `MUL` | 0x7 | Ra, Rb | `0111 aa bb 00000000` | Ra ← Ra × Rb (low 8 bits) | Z N |
| `INC` | 0x8 | Ra | `1000 aa 00 00000000` | Ra ← Ra + 1 | Z N |
| `DEC` | 0x9 | Ra | `1001 aa 00 00000000` | Ra ← Ra − 1 | Z N |
| `CMP` | 0xA | Ra, Rb | `1010 aa bb 00000000` | Ra − Rb, result discarded | Z N |
| `JMP` | 0xB | addr | `1011 00 00 dddddddd` | PC ← addr | - |
| `JZ` | 0xC | addr | `1100 00 00 dddddddd` | if Z = 1: PC ← addr | - |
| `JNZ` | 0xD | addr | `1101 00 00 dddddddd` | if Z = 0: PC ← addr | - |
| `HALT` | 0xF | — | `1111 00 00 00000000` | stop | - |

Z = 1 when the 8-bit result is 0. N = bit 7 of the result. Arithmetic wraps
modulo 256. Registers are encoded as `00`=R0, `01`=R1, `10`=R2, `11`=R3.

## Memory Map

| Address | Purpose |
|---------|---------|
| `0x00–0x7F` | Program instructions |
| `0x80–0xEF` | General data (free) |
| `0xF0` | **RESULT** |
| `0xF1` | Input operand (Program A `x = 8`, Program B `n = 5`) |
| `0xF2` | Loop variable `i` (Program B) |
| `0xF3–0xFF` | Scratch / reserved |

## Report

The PDF is already built: `docs/CPU_Design_Report.pdf`. To rebuild it, which
reruns the simulator and the tests to fill in every table and trace:

```bash
python3 -m pip install -r tools/requirements.txt
python3 tools/build_report.py
```
