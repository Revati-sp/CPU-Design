==========================================================================================
 MiniCPU-8 : 8-bit CPU, 16-bit instructions, 256-byte RAM
==========================================================================================
   +------------------------------- CPU --------------------------------+
   |  CONTROL UNIT : clock, phase FETCH -> DECODE -> EXECUTE             |
   |  SPECIAL REGS : PC (8)   IR (16)   MAR (8)   MDR (8)                |
   |  GENERAL REGS : R0  R1  R2  R3   (8 bits each)                      |
   |  ALU          : ADD SUB MUL INC DEC CMP  (A, B -> Y)    FLAGS: Z  N |
   +-------------------------------------+------------------------------+
            MAR -> address bus (8 bits)  |  MDR <-> data bus (8 bits)
            READ / WRITE control line    |
   ======================================+=================== SYSTEM BUS
                                         |
                          +--------------+--------------+
                          |        RAM  256 x 8 bits    |
                          |  0x00-0x7F code             |
                          |  0x80-0xEF free             |
                          |  0xF0-0xFF data (a, b, c)   |
                          +-----------------------------+

==========================================================================================
 INSTRUCTION SET   (word = oooo aa bb iiiiiiii : opcode, reg A, reg B, imm8/addr8)
==========================================================================================
  MNEMONIC  OPCODE  BINARY ENCODING       OPERANDS     OPERATION                   FLAGS
  --------  ------  --------------------  -----------  --------------------------  -----
  NOP       0x0     0000 00 00 00000000   -            no operation                -
  LDI       0x1     0001 aa 00 iiiiiiii   Ra, imm8     Ra <- imm8                  -
  LOAD      0x2     0010 aa 00 dddddddd   Ra, [addr]   Ra <- RAM[addr]             -
  STORE     0x3     0011 aa 00 dddddddd   Ra, [addr]   RAM[addr] <- Ra             -
  MOV       0x4     0100 aa bb 00000000   Ra, Rb       Ra <- Rb                    -
  ADD       0x5     0101 aa bb 00000000   Ra, Rb       Ra <- Ra + Rb               Z N
  SUB       0x6     0110 aa bb 00000000   Ra, Rb       Ra <- Ra - Rb               Z N
  MUL       0x7     0111 aa bb 00000000   Ra, Rb       Ra <- Ra * Rb (low 8 bits)  Z N
  INC       0x8     1000 aa 00 00000000   Ra           Ra <- Ra + 1                Z N
  DEC       0x9     1001 aa 00 00000000   Ra           Ra <- Ra - 1                Z N
  CMP       0xA     1010 aa bb 00000000   Ra, Rb       Ra - Rb (flags only)        Z N
  JMP       0xB     1011 00 00 dddddddd   addr         PC <- addr                  -
  JZ        0xC     1100 00 00 dddddddd   addr         if Z = 1: PC <- addr        -
  JNZ       0xD     1101 00 00 dddddddd   addr         if Z = 0: PC <- addr        -
  ---       0xE     1110 -- -- --------   -            reserved (fault)            -
  HALT      0xF     1111 00 00 00000000   -            stop the clock              -
  Registers: 00 = R0, 01 = R1, 10 = R2, 11 = R3.   Unused fields must be 0.
  Flags: Z = 1 if result is 0;  N = bit 7 of result.  Arithmetic wraps modulo 256.
